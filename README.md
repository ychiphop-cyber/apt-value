# 닥터마빈 아파트 가치진단

“지금 이 집값, 숫자로 설명될까?” — 아파트 가격이 **무엇으로 설명되는지** 진단하는 도구.
시세 조회도, 가격 예언기도 아니다. 실거래·금리·전세·수급·입지·학군·미래가치를 다섯 개 엔진으로 분리해
**적정가치 범위 · 주거가치 · 투자가치 · 가격매력도 · 신뢰도**를 제시한다.

## 구조

- `src/` — 앱 소스 (head.html + engine.js + ui.js)
- `config/` — 모든 계수·가중치·캡 (JSON이 원본, 코드 하드코딩 금지)
- `data/apartments.json` — 데모 샘플 단지 DB (출처·기준일 표기)
- `test/` — 엔진 단위 테스트 + 전 사례 회귀 테스트
- `tools/` — build.js(조립) · gate.js(AES-256 비밀번호 게이트)
- `index.html` — 배포본 (암호문만 포함, 비밀번호는 저장소에 없음)
- `docs/DESIGN.md` — 설계 문서

## 빌드·배포

```bash
echo -n '4자리비번' > .gate-password   # gitignored
./build.sh                             # 테스트 → 조립 → 암호화 → index.html
```

`index.html`을 GitHub Pages로 배포한다. 비밀번호를 바꾸려면 `.gate-password` 수정 후 재빌드.
계수를 바꾸려면 `config/*.json` 수정 후 재빌드 (테스트가 가드).

## 원칙 (PRD 요약)

- 정밀한 단일 가격을 말하지 않는다 — 항상 **범위 + 신뢰도**
- 좋은 아파트 ≠ 싼 아파트 — 세 점수 분리
- 프리미엄 중복가산 금지 — 카테고리 캡 + 총량 캡 + 비교거래 잔차만 반영
- 데이터가 없으면 없다고 말하고(신뢰도 하락) 계산은 계속한다
- 투자 권유가 아닌 이해 도구
